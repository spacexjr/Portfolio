# Space — Portfolio

Personal developer portfolio for [@spacexjr](https://github.com/spacexjr).

A responsive, single-page site with a visual identity inspired by BMO and retro-futuristic interfaces. The design uses a dark teal palette, restrained pixel/terminal details and lightweight CSS transitions.

## Run locally

No build step or package manager is required.

    git clone https://github.com/spacexjr/Portifolio.git
    cd Portifolio
    python3 -m http.server 8000

Open http://localhost:8000.

## Deployment

The repository can be published with GitHub Pages:

1. Open Settings → Pages.
2. Select Deploy from a branch.
3. Choose main and the root folder.
4. Save and wait for deployment to finish.
